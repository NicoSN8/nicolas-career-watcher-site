Who this applies to

Nicolas Career Watcher ("the program") is a personal tool. Its only intended user is Nicolas Su Nobrega, and it is meant to access only his own Google account (nicolassunobrega2@gmail.com). If another account is authorized by mistake, the program refuses to read it.

Google user data accessed

The program requests one Google permission: https://www.googleapis.com/auth/gmail.readonly. It uses it to:

  • read the account's email address, to confirm it is the expected account;
  • search for messages from job platforms (LinkedIn job alerts and application updates, Indeed job alerts and notices, Handshake) and read those messages.

The permission technically covers the entire mailbox. Limiting access to job-platform messages is done by the program's own search queries, not by Google. The program makes only read requests. It cannot send, delete, archive, label or mark messages.

What is stored, and where

Data is stored in a database on Nicolas's own computer, not on a hosted server. For each job-platform email it stores:

  • message ID, sender, subject and received date;
  • for each job listed: title, company, location, posting date when shown, salary text when shown, whether the email shows a quick-apply option, a short snippet of the job card, and the public job link with personal tracking parameters removed;
  • application-status events (for example "application sent" or "job closed") with company, title and date.

Full email bodies are not stored. OAuth credentials are stored only in a private folder on the same computer, readable only by Nicolas's user account. They are never published or logged.

How the data is used

Only to help Nicolas with his own job search. Fixed rules (no AI model) compare openings with his target roles and requirements, remove duplicates, and skip jobs he already applied to or that were closed. The results go into short alerts and a daily summary.

Limited Use

The program's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to provide the job-tracking features described above to Nicolas himself. It is not used for advertising, not sold, and not used to train generalized AI or machine-learning models. People read it only when Nicolas reviews his own data, including with Factory in his own sessions.

Retention and deletion

Records stay on Nicolas's computer until he deletes them. Access can be ended at any time:

  • revoke the app at myaccount.google.com/permissions;
  • delete the local token file and the local database.

Messages sent to Telegram stay in that chat until they are deleted there.

Security

Credentials are kept in a private local folder with restrictive file permissions. The program's code allows only read requests to Gmail and checks that the authorized account and permission are the expected ones before reading anything. The computer is a personal device. No security measure is perfect.
